# 验证记录：可访问性与提交者闭环

> 这是一份历史验证存档：记录指定版本、数据和环境下的用户可见结果。它不是产品介绍、开发日报或未来承诺。

**验证日期**：2026-10-30
**场景**：组织者工作区、提交者表单、展示视图、可访问性与首次提交
**环境**：隔离 SQLite；虚构种子；未配置模型密钥；桌面与 390/320px 视口
**性质**：版本验证存档

## 结论

主要页面和提交者闭环可以在桌面与窄屏环境中完成。键盘用户能够进入提交者逐步填写对话区；组织者上下文、辅助说明和状态文字具有明确的语义和可读对比度。提交者能够完成登录、填写、上传、保存草稿、刷新恢复、正式提交、查看回执和进入更正。

## 关键验证

| 范围 | 结果 |
| --- | --- |
| 可访问性结构 | 组织者登录、任务、设计、名册、工作台、复核、交付、提交者登录和表单均完成自动扫描，未发现明确 WCAG 违规 |
| 提交者填写区 | 滚动对话区可通过键盘聚焦，消息有可访问名称；材料限制、条件要求和错误说明均与文件控件关联 |
| 视觉可读性 | 低对比度辅助文字改为页面既有的高对比度颜色；渐变背景仍需人工判读，自动工具的 `incomplete` 不计作违规 |
| 提交闭环 | 上传、草稿、正式提交和检查结果刷新均能完成；上传不替代正式提交，正式版本和回执清晰呈现 |
| 展示与响应式 | Showcase 覆盖 1440、1366、390、320px；无横向溢出、控制台错误、页面异常或失败请求 |
| 新建任务 | 从任务创建、模板发布、名册发证到提交者首次提交和快照交付的隔离路径可复现 |

## 自动化与证据

使用 `scripts/showcase_check.cjs`、`scripts/ux_accessibility_check.cjs`、`scripts/ux_first_task_submitter_entry_walkthrough.cjs` 和前端契约测试完成验证。原始截图、axe 报告、机器测量和临时服务输出保存在当次验证目录或 `%TEMP%`，不作为产品数据提交。

## 限制

自动化 axe 扫描不能替代真实屏幕阅读器、辅助技术用户和实体移动设备测试；渐变背景上的颜色判断仍需人工复核。虚构种子和空模型密钥不代表真实模型准确率、provider 文件输入兼容性或公网部署安全。
