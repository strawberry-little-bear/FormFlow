# 2026-10-30 可访问性回归

## 发现与修复

- 展示路线的“当前演示任务”上下文原先是带 `aria-label` 的普通 `div`。axe 将其标记为需人工核查：该元素没有有效 role，名称不一定会被辅助技术识别。
- 为上下文增加 `role="group"`，保留“当前演示任务”名称；任务名称、当前焦点和两个操作仍在同一分组内。前端契约锁定该语义，静态资源版本更新至 `20261030-1`。

## 验收

- 使用 `%TEMP%\formflow-axe-20261030` 下的全新 SQLite 数据库、虚构种子和空模型密钥；API 与 Worker 运行于隔离环境，检查后均已停止。
- axe-core WCAG 2.1/2.2 A/AA 自动扫描覆盖组织者登录、任务、设计、名单、工作台、复核、交付及提交者登录：明确违规 0 项；浏览器控制台错误、页面异常和 HTTP 失败均为 0。
- 修复前 axe 将 `.presentation-task-context` 的 `aria-label` 列为需人工判读项；修复后同一隔离环境复扫，该节点不再出现在 axe 判读列表中。
- 背景渐变上的对比度节点和单字品牌标识仍有 axe 不确定项，未把它们记为确定违规；真实屏幕阅读器与辅助技术用户测试仍未覆盖。
