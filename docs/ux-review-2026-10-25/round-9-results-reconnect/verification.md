# 结果读取断线恢复走查

日期：2026-10-25。服务：`http://127.0.0.1:8000`。页面由浏览器真实加载；提交者 API 由 Playwright 路由拦截，以确定性夹具模拟第一次结果读取返回 503、联网恢复事件触发下一次读取成功。未写入演示数据。

首次读取失败后，提交者仍能看到回执和已提交材料，状态提示为“当前核对结果暂时读不到”，不再同时显示“正在读取这份提交的核对结果”。页面保留手动重试入口。连续两次派发 `online` 事件：第一次重读仍返回 503，离线提示与下一步状态保持一致；第二次重读返回 200 并显示恢复结果。

验证：`node --test tests/frontend_contracts.test.cjs`，138 项通过；`node scripts/ux_results_reconnect.cjs`，结果请求 3 次（503、503、200），离线提示、失败后状态一致和最终恢复均通过，未注入之外的控制台错误为 0，页面异常为 0。浏览器报告和截图在本目录的 `results.json`、`results-offline.png`、`results-reconnected.png`。

限制：503 是路由夹具返回，不是操作系统层面的真实断网；两次注入的 503 各产生一条预期浏览器资源错误日志。慢响应以及组织者工作台的网络故障仍待走查。
