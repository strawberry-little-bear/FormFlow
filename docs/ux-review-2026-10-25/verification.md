# 验证档案：展示入口与双角色路径

> 这是一份历史验证存档：记录指定版本、数据和环境下的用户可见结果。它不是产品介绍、开发日报或未来承诺。

**验证日期**：2026-10-25
**对象**：展示首页、组织者工作区、提交者首次提交、MCP 只读桥、窄屏布局
**环境**：隔离演示数据库；虚构种子；空模型密钥；1440、390、320px 浏览器视口
**性质**：展示与回归证据档案

## 结论

第一次打开作品的观众可以从展示首页进入组织者和提交者两条路径。组织者能从任务、设计、名册、收集、复核走到交付；提交者能完成凭证登录、填写、上传、保存草稿、正式提交和查看回执。展示状态、Agent runtime、MCP 只读回放和人工接管边界在桌面与窄屏上保持可见，离线模型结果不会被描述成实时推理。

## 验证结果

| 场景 | 结果 |
| --- | --- |
| 展示入口 | 展示首页、任务列表、当前焦点、组织者站点和提交者入口均可加载；退出展示后任务列表仍可见 |
| 组织者路径 | 任务、需求设计、名单与凭证、收集工作台、证据复核、交付与归档可连续访问；无效名册和复核编号显示可操作失败态 |
| 提交者路径 | 凭证登录、字段填写、材料上传、服务器草稿、正式提交、检查进度和回执可完成；缺项会定位到对应字段或材料槽位 |
| 运行状态 | Agent runtime 的排队、运行、完成和失败状态与人工接管入口分开显示；MCP 只读桥只返回授权的聚合信息 |
| 移动视口 | 390px 与 320px 没有整页横向溢出；展示卡片、工作台操作和提交者主操作保持可用 |
| 自动检查 | 浏览器控制台、页面异常和意外失败请求均为 0；前端契约、Python 回归、启动器和 MCP 协议检查通过 |
