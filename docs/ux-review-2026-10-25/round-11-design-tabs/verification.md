# 2026-10-25 设计台页签键盘与读屏复核

## 发现与处理

设计台“提交者预览 / 规则与依据”使用了 `role=tab`，但没有方向键、Home/End 键操作、单一 Tab 停靠或页签与面板的可访问名称关联。切换时整个草案区域会重新渲染，原焦点也会丢失。

现已补齐页签键盘操作和 roving tabindex；切换后焦点回到当前页签。两个页签都关联同一内容面板，面板的 `aria-labelledby` 随当前视图同步更新。

## 浏览器验证

- 环境：本机 `127.0.0.1:8000` 演示登录，设计台任务 1；未写入业务数据。
- `ArrowRight` 从“提交者预览”切到“规则与依据”；焦点、`aria-selected`、`tabindex` 和面板 `aria-labelledby` 同步。
- `Home` 返回“提交者预览”；`End` 切到“规则与依据”；每次切换后焦点均保留在当前页签。
- 1440、390、320px 下 `documentElement.scrollWidth` 与视口宽度相同；浏览器控制台错误和页面异常均为 0。
- 前端契约新增一项覆盖键盘切换、无效页签保护、页签/面板关系与焦点恢复。

截图与机器结果：`design-tabs-1440.png`、`design-tabs-390.png`、`design-tabs-320.png`、`results.json`。
