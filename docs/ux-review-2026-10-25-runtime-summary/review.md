# 2026-10-25 展示页 Agent 信息层级复核

## 观察与处理

展示模式会自动展开 Agent 工作导览；runtime 区虽可折叠，但摘要里仍重复列出需求整理与证据复核两张 Agent 卡片。手机上两块内容连续出现，角色说明重复，拉长了首次浏览路径。

将 runtime 摘要改为「运行时边界与安全护栏」，仅呈现模型状态和当前任务状态；Agent 职责与业务阶段集中由导览说明。工具白名单、Harness、MCP 边界和人工决定仍可通过键盘或点击展开查看。普通工作模式下 runtime 也保持默认收起。

复核普通工作模式后发现，完全移除 Agent 概览会让收起状态看不出双 Agent 的分工。现为普通模式补回一行角色概括；展示模式隐藏该行，由自动展开的导览承载完整说明，避免重复。

## 验证

- 前端契约：131 项通过。
- 1440px、390px、320px：页面宽度均未超过视口。
- 展示模式默认导览展开、runtime 收起；390px 下展开 runtime 后，审核 Skill、工具白名单、Harness、MCP 边界和人工决定均可见。
- 普通工作模式的 runtime 摘要直接显示需求 Agent 与审核 Agent 的分工；展示模式不重复显示这行摘要。
- 浏览器控制台错误与本地 4xx/5xx 请求：0。
- 桌面和手机截图及测量结果见本目录 `desktop.png`、`mobile-390.png`、`mobile-320.png` 和 `results.json`。

此轮只复核任务首页的层级与响应式显示；未进行目标用户理解度测试。
