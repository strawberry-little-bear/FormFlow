# 展示页 Agent 信息层级


> 这是一份历史验证存档：记录指定版本、数据和环境下的用户可见结果。它不是产品介绍、开发日报或未来承诺。

## 页面表现

展示模式自动展开 Agent 工作导览，运行时摘要聚焦模型状态和当前任务状态；Agent 职责与业务阶段集中在导览中，避免手机端重复出现两套说明。工具白名单、Harness、MCP 边界和人工决定可通过展开内容查看。普通工作模式保留一行双 Agent 概括，并默认收起详细运行信息。

## 验证

- 前端契约：131 项通过。
- 1440px、390px、320px：页面宽度均未超过视口。
- 展示模式默认导览展开、runtime 收起；390px 下展开 runtime 后，审核 Skill、工具白名单、Harness、MCP 边界和人工决定均可见。
- 普通工作模式的 runtime 摘要直接显示需求 Agent 与审核 Agent 的分工；展示模式不重复显示这行摘要。
- 浏览器控制台错误与本地 4xx/5xx 请求：0。
- 桌面和手机截图及测量结果见本目录 `desktop.png`、`mobile-390.png`、`mobile-320.png` 和 `results.json`。

此轮只复核任务首页的层级与响应式显示；未进行目标用户理解度测试。
