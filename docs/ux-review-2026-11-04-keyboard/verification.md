# 2026-11-04 键盘路径回归

本轮针对第一次使用者的组织者和提交者路径，补充了可重复的键盘回归 harness。测试使用隔离演示数据库、空模型密钥和 `127.0.0.1:8051`，不会写入仓库内演示数据。

## 覆盖范围

`scripts/ux_keyboard_paths.cjs` 逐页从 `main#app` 开始发送 Tab，记录页面当前可见、可操作控件是否都能获得焦点，并检查焦点没有落入隐藏元素。组织者覆盖任务、需求设计、名册、收集工作台、证据复核和交付；提交者覆盖认证后的填写表单。

复核页折叠的 `<details>` 内容不属于当前可见控件，因此从期望集合排除。需求设计页的 Agent runtime 区域会异步渲染，脚本在采集前等待稳定状态，避免把动态内容误判为缺失。

## 结果

- 组织者 6 条路由：全部可见控件均可通过 Tab 到达。
- 提交者认证表单：全部可见控件均可通过 Tab 到达。
- 缺失焦点控件：0。
- 焦点进入隐藏元素：0。
- 浏览器错误：0。
- 失败 HTTP 响应：0。
- 结果明细：`keyboard-results.json`。

本轮没有发现需要修改业务代码的新缺陷；新增内容是回归脚本与验证证据。该检查不等同于真实 NVDA、VoiceOver 或 TalkBack 验收，屏幕阅读器、真实移动设备和键盘布局仍需单独确认。
