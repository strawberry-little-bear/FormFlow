# FormFlow 文档

这里的文档按使用场景排列。第一次接触作品时，从根目录 [README](../README.md) 开始；想直接运行演示、接入模型或查看验证证据时，进入对应入口。

## 先看作品

- [体验指南](demo-guide.md)：按组织者和提交者的顺序走完一条完整演示路径。
- [产品状态与方向](product-roadmap.md)：查看产品边界、当前能力和下一步建设方向。
- [交互设计说明](interaction-optimization.md)：了解工作台、提交页和证据复核页的信息组织方式。

## 运行与接入

- [部署与模型接入](deployment.md)：本地启动、生产部署、文件输入模式、密钥保存位置和数据边界。
- [审核 Agent 评估集](review-agent-evaluation.md)：在获准的脱敏案例上评估结论、证据覆盖和人工修正。

## 查验证据

- [验证档案索引](ux-review-index.md)：按日期和场景查找截图、脚本、自动化结果与限制条件。
- `ux-review-*` 目录：指定版本、虚构或获准数据、浏览器视口和运行配置下的历史验证记录。

验证档案用于说明某个版本在什么条件下表现如何。它们是可追溯的体验证据，不是产品宣传页，也不替代当前代码、部署配置或真实材料验收。
