# FormFlow 文档

FormFlow 把“收什么”与“收到后怎么核验”放在同一条可追溯流程里。这里的文档按读者目标组织，第一次了解作品时从根目录 [README](../README.md) 开始。

## 先体验

- [体验指南](demo-guide.md)：用虚构演示数据走完组织者和提交者两条路径。
- [交互设计说明](interaction-optimization.md)：了解页面如何表达状态、证据和下一步动作。

## 接入与评估

- [部署与模型接入](deployment.md)：本地启动、生产部署、文件输入优先级、密钥位置和数据边界。
- [审核 Agent 评估集](review-agent-evaluation.md)：在获准的脱敏案例上比较结论、证据覆盖和人工修正。
- [产品状态与方向](product-roadmap.md)：查看当前能力、验证边界和后续建设方向。

## 查验证据

- [验证档案索引](ux-review-index.md)：按场景查找截图、脚本、自动化结果和限制条件。
- `ux-review-*` 目录：保存指定版本、虚构或获准数据、浏览器视口和运行配置下的历史验证记录。

验证档案回答的是“在什么条件下看到了什么结果”。它们用于追溯体验和回归范围，不替代当前代码、部署配置、真实模型评估或生产验收。
