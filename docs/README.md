# FormFlow 文档

这里的文档按访客的阅读目标组织。第一次了解作品时，从体验指南开始；准备接入真实模型时，再看部署说明；需要核对实现边界或复现某个页面时，进入验证档案。

## 了解作品

- [体验指南](demo-guide.md)：用虚构数据走完组织者和提交者两条路径。
- [交互设计说明](interaction-optimization.md)：了解页面如何表达材料状态、审核状态、证据和下一步动作。
- [产品状态与方向](product-roadmap.md)：查看当前能力、边界和后续建设方向。

## 运行与接入

- [部署与模型接入](deployment.md)：本地启动、生产部署、provider、原始文件输入、文字解析/OCR 降级和密钥边界。
- [审核 Agent 评估集](review-agent-evaluation.md)：在获授权的脱敏材料上评估结论、证据覆盖和人工修正。

## 核对证据

- [验证档案索引](ux-review-index.md)：按用户场景进入收集、审核、交付、Agent 运行和可访问性记录。
- `ux-review-*`：保存指定版本、演示数据和浏览器环境下的可复现结果。

验证档案是产品证据，不是开发日报或个人汇报稿。它们只说明某个场景在指定环境下看到了什么，同时明确没有覆盖的 provider、材料、设备或生产条件。产品定位和使用方式以根目录 [README](../README.md) 为准。
