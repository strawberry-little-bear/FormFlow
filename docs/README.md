# FormFlow 文档

这里的文档分成两层：面向访客的作品说明，以及面向复现者的运行和验证材料。第一次了解 FormFlow 时从根目录 [README](../README.md) 和演示指南开始；只有需要部署、评估或复核具体版本时，再进入下面的技术文档。

## 先看作品

- [五分钟演示指南](demo-guide.md)：从组织者设计任务、提交者提交材料，到审核和交付的现场讲解顺序。
- [部署与模型接入](deployment.md)：本地启动、生产部署边界、模型输入模式和密钥处理方式。

## 了解设计

- [产品路线图](product-roadmap.md)：当前能力、下一阶段方向和仍需验证的边界。
- [交互设计说明](interaction-optimization.md)：组织者、提交者和展示视图的信息架构。
- [审核 Agent 评估集](review-agent-evaluation.md)：如何在获准脱敏数据上评估结论、证据和人工修正。

## 查验证据

- [走查证据索引](ux-review-index.md)：按主题找到浏览器截图、自动化结果和限制说明。
- `ux-review-*` 目录：特定日期、种子数据、浏览器和端口下的验证存档。

走查记录是可复现性材料，不是产品承诺，也不是开发日报。它们只回答“指定版本在指定环境下验证了什么”；产品能力以根目录 [README](../README.md)、当前代码和部署文档为准。记录中的端口、提交号、测试数量和截图只用于定位当时的验证环境。
