## 模型和数据边界

审核优先使用部署者选择的模型读取原始 PDF 或图片；provider 不支持、文件超限或调用失败时，才使用文字解析或 OCR。确定性检查负责文件和字段约束，Agent 负责语义理解和跨文件比对，组织者负责最终确认。

API Key 只在部署者本地环境、`.env` 或部署平台 Secret 中配置。FormFlow 不把密钥写入数据库、浏览器响应、日志、审计事件或 MCP；材料是否发送给外部 provider 由部署者决定。

验证档案按场景记录用户可见结果和复现边界。虚构种子可以验证流程、权限、状态和导出行为；真实模型质量、敏感材料处理、屏幕阅读器和公网部署需要在授权环境中单独验收。
