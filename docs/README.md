## 想核对产品行为

[验证档案索引](ux-review-index.md) 按用户目标组织截图、浏览器脚本、运行条件和限制。它是可复现的产品证据，不是开发日报；日期、端口、提交号和测试数量只用于定位对应环境。

常用入口：

- [收集、审核与交付](ux-review-2026-10-23/verification.md)：第一次打开作品时的组织者和提交者主路径。
- [来源资料如何进入需求 Agent](ux-review-2026-11-06-requirements-agent/verification.md)：通知、名单和模板如何进入需求蓝图。
- [启动参数与失败状态](ux-review-2026-10-26b/feedback.md)：自定义端口、无效路由和责任边界的恢复体验。

项目的完整定位和快速开始以根目录 [README](../README.md) 为准。
