# FormFlow 文档

这里的文档按读者要完成的事情组织。第一次了解作品时看根目录 [README](../README.md)；准备运行、部署或复核实现时，再进入对应章节。

## 了解产品

- [体验指南](demo-guide.md)：从资料上传、需求整理到审核和交付的完整演示路径。
- [交互设计说明](interaction-optimization.md)：组织者、提交者和证据复核页如何组织信息、状态和下一步动作。
- [产品状态与方向](product-roadmap.md)：当前产品边界、已具备的能力和后续建设方向。

## 运行与接入

- [部署与模型接入](deployment.md)：本地启动、生产部署、模型输入模式、密钥保存位置和数据边界。
- [审核 Agent 评估集](review-agent-evaluation.md)：在获准脱敏数据上评估结论、证据覆盖和人工修正。

## 查看验证证据

- [验证档案索引](ux-review-index.md)：按场景查找截图、脚本、自动化结果和限制条件。
- `ux-review-*` 目录：指定版本、虚构或获准数据、浏览器视口和运行配置下的可复现验证记录。

验证档案说明“在什么条件下验证了什么”。它们用于解释体验覆盖和边界，不替代当前代码、部署配置或真实材料验收。
