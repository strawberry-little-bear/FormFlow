# FormFlow 文档

这组文档按读者要完成的事情组织。第一次了解作品，从根目录 [README](../README.md) 开始；想亲自走一遍流程、接入自己的模型或核对截图与脚本，再进入下面的入口。

## 先看体验

- [体验指南](demo-guide.md)：从演示登录开始，走完组织者和提交者两条路径。
- [交互设计说明](interaction-optimization.md)：解释工作台、提交页和证据复核页如何表达状态、证据和下一步动作。

## 再看接入

- [部署与模型接入](deployment.md)：本地启动、生产部署、文件输入优先级、密钥位置和数据边界。
- [审核 Agent 评估集](review-agent-evaluation.md)：在获准的脱敏案例上比较结论、证据覆盖和人工修正。
- [产品状态与方向](product-roadmap.md)：查看当前能力、明确边界和后续建设方向。

## 最后核对证据

- [验证档案索引](ux-review-index.md)：按场景查找截图、脚本、自动化结果和限制条件。
- `ux-review-*` 目录：保存指定版本、演示数据、浏览器视口和运行配置下的验证档案。

验证档案回答三个问题：在什么条件下运行、访客看到了什么、结论不能外推到哪里。它们用于复现和评估产品体验，不要求读者阅读开发过程，也不替代真实模型评估或生产验收。
