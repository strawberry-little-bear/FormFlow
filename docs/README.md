# FormFlow 文档导航

从产品体验到本地部署，FormFlow 的文档按读者要完成的事情组织。第一次打开项目时，先看根目录 [README](../README.md)；需要复现某项体验时，再进入验证档案。

## 先体验

- [体验指南](demo-guide.md)：从整理要求到导出交付包的完整路径。
- [部署与模型接入](deployment.md)：本地启动、生产部署、模型输入模式和密钥边界。

## 再了解能力

- [产品状态与方向](product-roadmap.md)：当前能力、待补齐能力和验证边界。
- [交互设计说明](interaction-optimization.md)：组织者、提交者和审核页如何组织信息与状态。
- [审核 Agent 评估集](review-agent-evaluation.md)：在获准脱敏数据上评估结论、证据和人工修正。

## 查验证据

- [验证档案索引](ux-review-index.md)：按体验主题查找截图、脚本和结论。
- `ux-review-*` 目录：指定版本、数据边界和浏览器环境下的可复现记录。

验证档案记录“在什么条件下验证了什么”，包括数据边界、浏览器视口、脚本、截图和限制。它们补充产品文档，不替代当前代码和部署说明。
