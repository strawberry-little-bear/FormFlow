# FormFlow 文档入口

这里的文档服务于两种读者：第一次查看作品的人，以及需要运行、部署或复现验证的人。产品定位和最短运行路径在根目录 [README](../README.md)；本页提供按目的查找的入口。

## 先体验

- [五分钟演示指南](demo-guide.md)：从创建收集任务到导出交付包的完整展示顺序。
- [部署与模型接入](deployment.md)：本地启动、生产部署、文件输入模式和密钥边界。

## 了解设计

- [产品路线图](product-roadmap.md)：当前能力、后续方向与验证边界。
- [交互设计说明](interaction-optimization.md)：组织者、提交者和审核页如何组织信息与状态。
- [审核 Agent 评估集](review-agent-evaluation.md)：在获准脱敏数据上评估结论、证据和人工修正。

## 查验证据

- [走查证据索引](ux-review-index.md)：按体验主题找到截图、脚本和结论。
- `ux-review-*` 目录：指定日期、版本、种子数据和浏览器环境的历史存档。

验证记录是可复现的产品档案，使用“场景、结果、证据、限制”的结构。记录中的日期、端口、提交号和测试数量只用于还原当时的环境，不是产品承诺、开发日报或个人汇报；当前能力以代码、根 README 和部署文档为准。
