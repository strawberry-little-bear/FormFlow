## 产品主线

需求 Agent 读取通知、名单、模板和补充说明，生成带来源和澄清问题的收集蓝图。组织者确认蓝图后发布任务，提交者填写身份信息、上传材料、保存草稿并正式提交。审核 Agent 对照已发布规则比较表单、名单和多份材料，逐条输出 `satisfied`、`issue`、`unknown` 或 `failed`，并把证据位置与责任归属放在结果旁边。

确定性程序处理文件和状态约束，模型负责理解、比较和解释。Skill 固定 Agent 的步骤与输出格式，Harness 约束范围、工具、预算、超时和人工接管，MCP 提供受限的只读运行信息。API Key 只由部署者保存在本地配置或部署平台 Secret 中，不进入数据库、响应、日志或 MCP。

## 关于产品证据

`ux-review-*` 目录按用户场景保存产品档案。每份档案都说明入口、数据、页面结果、复现方式和边界；目录名中的日期和轮次只用于定位版本，不代表开发进度。

虚构种子和离线轨迹可以验证流程、权限、状态和导出行为。真实 provider、敏感材料、模型质量、屏幕阅读器、实体移动设备和公网部署仍需在获准环境中单独验收。
