## 查看验证记录

- [走查证据索引](ux-review-index.md)：按体验主题找到截图、脚本和结论。
- `ux-review-*` 目录：指定日期、版本、种子数据和浏览器环境的历史存档。

验证记录的作用是说明某个版本在某个环境中验证过什么。它们不是开发日报，也不替代当前代码、根目录 README 或部署文档；记录里的端口、提交号和测试数量只用于复现当时的场景。
