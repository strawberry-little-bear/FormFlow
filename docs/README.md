# FormFlow 文档

按使用目的选择入口：

## 先体验

- [体验指南](demo-guide.md)：用虚构演示数据走完组织者和提交者路径。
- [交互设计说明](interaction-optimization.md)：了解页面如何区分材料状态、处理状态、证据和下一步动作。

## 再接入

- [部署与模型接入](deployment.md)：本地启动、生产部署、provider、文件输入模式和密钥边界。
- [审核 Agent 评估集](review-agent-evaluation.md)：在获授权的脱敏案例上评估结论、证据覆盖和人工修正。
- [产品状态与方向](product-roadmap.md)：当前能力和后续建设重点。

## 最后核对

- [验证档案索引](ux-review-index.md)：按场景查看截图、脚本、运行条件和限制。
- `ux-review-*`：保存指定版本、演示数据和浏览器环境下的验证记录。

验证档案描述可复现的用户可见结果。它们不是开发日报，也不替代真实模型评估、屏幕阅读器测试或生产验收。
