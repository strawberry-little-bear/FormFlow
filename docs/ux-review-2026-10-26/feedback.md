# 体验档案：收集、复核与交付

## 档案用途

这份记录描述 FormFlow 在虚构演示数据、未配置模型密钥和本地浏览器中的用户可见行为。它用于追溯组织者、提交者、证据复核和交付归档路径，不代表真实模型质量或公网部署验收。

## 覆盖场景

| 场景 | 用户可完成的操作 | 结果边界 |
| --- | --- | --- |
| 登录与任务列表 | 进入组织者或提交者入口，查看任务和待办 | 仅覆盖演示账号和虚构种子 |
| 收集工作台 | 区分应交、免交、已提交和已验收，并定位下一步 | 组织者仍决定补正和验收 |
| 需求设计 | 查看蓝图、规则、时间策略、来源资料和发布前核对 | 草案必须经组织者确认后才会发布 |
| 名单与凭证 | 查看名单、发放状态和重复主体提示 | 不自动合并同名主体 |
| 证据复核 | 按提交者查看规则结论、原文位置和覆盖明细 | 模型引用是定位线索，需人工核对原文 |
| 交付与归档 | 生成快照、CSV 和 ZIP，并查看排除原因 | 快照只纳入符合当前验收条件的版本 |
| 提交者流程 | 填写字段、上传材料、保存草稿、正式提交和补正 | 上传不等于正式提交 |

## 关键行为

- 未配置模型密钥时，材料仍会被接收；语义检查显示“未完成”，不会自动改判为材料不合格。
- 程序可确定的文件类型、数量、大小、时间和导出规则由确定性检查处理。
- 需要理解内容、跨文件比对或排版的项目由审核 Agent 提供结果，并保留 `unknown` 与 `failed` 两种人工接手状态。
- 390px 和 320px 视口下，登录、工作台、设计、复核和提交者页面保持可用，没有整页横向溢出。

## 记录边界

验证使用指定版本、虚构数据和本地浏览器。它没有覆盖真实 provider 的材料处理政策、真实用户试点、屏幕阅读器认证或公网安全验收。
