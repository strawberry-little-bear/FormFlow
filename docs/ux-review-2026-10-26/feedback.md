# 体验档案：组织者、提交者与复核

这份公开档案记录 FormFlow 在虚构演示数据、未配置模型密钥和本地浏览器中的用户可见结果。它覆盖组织者与提交者的主要路径、证据复核、交付归档和窄屏布局。

## 用户可以完成的事情

提交者可以登录、填写身份字段、上传多个材料、保存服务器草稿、刷新恢复并正式提交。组织者可以查看收集进度、打开逐项复核结果、处理补正和人工判断，再生成交付快照以及 CSV、ZIP 导出。

当模型不可用时，语义检查会明确显示“未完成”，已收到的材料仍可交给人工处理，不会被自动显示成不合格。

## 验证结果

| 场景 | 用户可见结果 |
| --- | --- |
| 演示启动 | Windows 中文环境下，启动器稳定读取进程列表，并保留可读的失败提示。 |
| 提交者操作区 | 320px 窄屏下，主要提交入口保持可见，次要操作不会挤压主流程。 |
| 复核状态 | “已满足”和“阻塞验收”分开呈现，检查结论与验收属性不会混在一起。 |
| 错误提示 | 服务端已有具体原因时直接展示，重复的系统前缀只作为兜底。 |
| 交付 ZIP | 条目保留快照或原件时间，不再出现统一的 1980-01-01 默认时间。 |
| 截止时间 | 跨年日期显示完整年份，避免用户自行推断。 |
| 模型配置 | 模型不可用时提供配置入口和下一步说明，组织者仍能继续人工处理。 |

## 覆盖与边界

密码和凭证错误、无效任务与设计编号、重复上传、催交排除规则、快照导出、390/320px 横向溢出和基础键盘路径均有对应验证。结论只适用于指定版本、虚构数据和本地浏览器，不代表真实模型质量、真实材料处理、屏幕阅读器体验或公网部署已经验收。
