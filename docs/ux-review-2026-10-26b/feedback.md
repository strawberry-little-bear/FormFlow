# 体验证据：端口启动、失败态与责任分工

这页记录首次打开 FormFlow 时最容易影响理解的四个场景，并给出当前产品应呈现的结果。数据为虚构演示数据，模型密钥留空；评审者可以按表格中的入口复现。

## 访客路径

| 场景 | 应看到什么 | 下一步由谁完成 |
| --- | --- | --- |
| `--reset --port 8011` | 检查 8011，并在真正被占用时报告 8011；空闲时正常启动 | 启动者处理端口冲突 |
| `#/roster/9999` | 任务不存在的错误说明、返回入口和重新加载动作 | 组织者选择有效任务 |
| `#/review/1/9999` | 主体不存在的错误说明；不再保留“正在读取检查结果…”的加载占位 | 组织者选择有效提交者 |
| 提交者查看已提交材料 | 可自己处理的缺项单独列出；检查未完成、组织者核对和等待验收放入组织者区域 | 提交者改材料，组织者做确认 |

## 复现与边界

截图、运行条件和浏览器脚本位于本目录。该证据页只说明页面在虚构数据和本地浏览器中的恢复行为；真实模型输入、敏感材料处理、生产并发和公网部署需要单独验收。
