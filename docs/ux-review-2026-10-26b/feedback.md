# 验证档案：启动参数、失败状态与责任分工

这份档案是上一份入口验证的精简复现卡，方便评审者快速确认端口参数、无效路由和提交者责任分区的结果。数据为虚构演示数据，模型密钥留空。

## 场景与结果

| 场景 | 应看到什么 | 后续动作 |
| --- | --- | --- |
| `--reset --port 8011` | 启动器检查并使用 8011；冲突提示不会误报 8000 | 启动者处理端口冲突 |
| `#/roster/9999` | 任务不存在的说明、返回入口和重新加载动作 | 组织者选择有效任务 |
| `#/review/1/9999` | 主体不存在的说明，加载占位被清除 | 组织者选择有效提交者 |
| 提交者查看检查结果 | 自己能处理的缺项与组织者待办分区展示 | 提交者改材料，组织者做确认 |

## 复现边界

截图、运行条件和浏览器脚本位于本目录。档案只说明虚构数据和本地浏览器中的恢复行为；真实模型输入、敏感材料处理、生产并发和公网部署需要在授权环境中单独验收。
