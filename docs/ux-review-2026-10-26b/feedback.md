# 场景档案：异常入口的恢复路径

当启动参数、任务地址或检查状态异常时，FormFlow 会把用户带回一条可以继续的路径，并保留真实状态。

| 用户动作 | 用户看到的结果 | 下一步 |
| --- | --- | --- |
| 使用 `--reset --port 8011` 启动 | 启动器检查 8011，并报告真实的端口冲突 | 选择可用端口后重试 |
| 访问不存在的名册任务 | 页面说明任务不存在，并提供返回入口 | 选择有效任务 |
| 访问不存在的提交者复核页 | 页面说明主体不存在，加载占位被清除 | 选择有效提交者 |
| 查看提交后的检查结果 | 提交者能处理的缺项与组织者待办分开显示 | 提交者改材料，组织者做确认 |

页面状态同时说明原因和动作。材料检查尚未完成时，界面保留“待处理”语义，不把它写成不合格；组织者确认事项也不会伪装成提交者需要修改的内容。

截图、运行条件和浏览器脚本位于本目录。档案覆盖虚构数据和本地浏览器中的恢复行为；真实模型输入、敏感材料处理、生产并发和公网部署仍需在授权环境中单独验收。
