# 评审记录：三条关键恢复路径

本页是启动器和主要工作页面的快速复核卡，方便访客直接看到异常发生时系统如何收尾。演示数据为虚构数据，模型密钥留空。

| 入口 | 页面应显示 | 用户下一步 |
| --- | --- | --- |
| `--reset --port 8011` | 检查 8011 并报告真实端口冲突 | 选择可用端口后重试 |
| `#/roster/9999` | 任务不存在、返回入口和重新加载动作 | 选择有效任务 |
| `#/review/1/9999` | 主体不存在，且清除加载占位 | 选择有效提交者 |
| 提交者检查结果 | 自己能处理的缺项与组织者待办分开 | 提交者改材料，组织者做确认 |

截图、运行条件和浏览器脚本位于本目录。记录只说明虚构数据和本地浏览器中的恢复行为；真实模型输入、敏感材料处理、生产并发和公网部署需要在授权环境中单独验收。
