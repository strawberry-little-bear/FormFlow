# 体验档案：启动参数与失败状态

## 读者可见范围

这份体验档案聚焦演示环境中的启动器、无效路由、提交者进度以及错误恢复。结果来自虚构种子、未配置模型密钥和本地浏览器，用来说明产品的恢复边界，不是开发汇报或生产承诺。

## 已确认的用户可见行为

| 场景 | 结果 |
| --- | --- |
| 自定义端口 | 启动器检查并启动用户传入的端口，错误提示与实际端口一致。 |
| 无效名册路由 | `#/roster/9999` 清除加载占位，说明任务不存在，并提供返回工作台入口。 |
| 无效复核路由 | `#/review/1/9999` 清除加载占位，只保留主体不存在的错误状态和返回入口。 |
| 提交者进度 | 提交者补正项与组织者待确认项分开显示，不把模型未完成或组织者核对伪装成提交者待办。 |

## 当前边界

展示登录后的任务列表可以更早出现；320px 下“重新加载服务器草稿”需要保持完整可读；交付页和复核页的重复入口与统计口径仍有收敛空间；设计页左栏后半段可以增加更清晰的内容层次。这些是当前体验边界，不改变本档案对上述失败态的结论。

## 记录边界

结论只适用于指定版本、虚构数据和本地浏览器，不代表真实模型、真实材料处理或公网部署已经验收。
