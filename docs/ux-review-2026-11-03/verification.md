# 验证档案：空库首次启动与完整闭环


> 这是一份历史验证存档：记录指定版本、数据和环境下的用户可见结果。它不是产品介绍、开发日报或未来承诺。

## 范围

- 环境：全新本地演示数据库，演示服务 `127.0.0.1:8022`，演示启动器保持空模型密钥。
- 数据：执行 `python scripts/start_demo.py --reset --port 8022` 生成虚构种子；Showcase 和 Axe 扫描只读路由与页面状态。
- 覆盖：任务、设计、工作台、复核、交付、名册无效编号、复核无效编号、设计无效任务；1440、1366、390、320px 四档视口。另扫描组织者登录、任务、设计、名册、工作台、复核、交付和提交者入口的 WCAG 2.1/2.2 A/AA。

## 用户可见结果

- Showcase：8 条路线 × 4 档视口，32 个路线场景全部通过。
- 任务筛选可以选中单一状态并通过空态清除条件恢复列表；退出展示视图后任务列表可见、可聚焦。
- 无效名册、复核主体、设计任务均显示可操作的恢复入口；复核页无残留加载占位。
- 四档视口均无整页横向溢出；浏览器控制台错误、页面异常和失败 HTTP 响应均为 0。
- Axe 扫描 8 个视图，明确违规为 0。短字标、单个符号和渐变背景被 Axe 列为 `incomplete`，这表示自动工具无法判定；它们没有计入通过证据，仍需人工确认。
- Python：450 项通过。前端契约：240 项通过。`node --check app/static/app.js` 与 `node --check scripts/showcase_check.cjs` 通过。

## 记录边界

该次验证没有发现可复现的新产品缺陷，因此没有改动功能代码。复核报告和截图保存在隔离工作副本的 `data/demo/showcase-current/` 与 `data/demo/accessibility-current.json/`；隔离演示服务在验证后关闭。
