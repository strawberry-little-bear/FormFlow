# 验证档案：展示与提交者闭环

**场景**：组织者展示路线、提交者首次提交与更正、任务生命周期、键盘路径
**环境**：隔离演示库、虚构材料、未配置模型密钥、1440/1366/390/320px 浏览器
**用途**：确认作品首屏、主要操作和离线降级状态可被理解

## 结果

| 验证范围 | 结论 |
| --- | --- |
| 组织者展示路线 | 任务列表、设计、名单、工作台、复核、交付和无效编号恢复均可完成 |
| 提交者闭环 | 凭证登录、字段填写、上传、服务器草稿、正式提交、回执和更正均可完成 |
| 任务生命周期 | 关闭、恢复和归档状态清晰；归档后不可用动作被隐藏 |
| 响应式视口 | 主要路径没有整页横向溢出 |
| 键盘与自动化 | 可见控件可达；浏览器错误、页面异常和失败 HTTP 响应为 0 |
| 导出交付 | 验收后的快照可以生成 CSV 与 ZIP，并保留排除原因 |

## 产品结论

第一次打开作品的用户可以分辨组织者和提交者各自的职责。无模型密钥时，语义检查明确显示“未完成”，材料仍可保留并交给人工处理。复核页把程序检查、语义检查和人工确认分开呈现，能够展示证据链和人工接管边界。
