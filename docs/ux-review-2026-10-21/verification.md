# 验证档案：复核范围、恢复与交付边界

> 这是一份历史验证存档：记录指定版本、数据和环境下的用户可见结果。它不是产品介绍、开发日报或未来承诺。

**验证日期**：2026-10-21 至 2026-10-22
**对象**：组织者复核页、需求 Agent、提交者草稿与正式回执、交付快照
**环境**：隔离 SQLite、虚构种子、空模型密钥；桌面与窄屏浏览器
**性质**：版本验证档案，证据以本目录截图、脚本和测试结果为准

## 结论

复核页会把当前账号、任务、主体、发布蓝图、正式修订、登记成员和检查运行绑定成一个不可见的范围标识。范围变化时，旧理由和人工决定不会被复用；过期请求返回冲突并且不写入数据库。需求 Agent、提交者草稿、正式回执和交付快照也保持版本边界，页面刷新或断线恢复时不会静默覆盖新内容。

## 验证结果

| 能力 | 验证结论 |
| --- | --- |
| 复核范围隔离 | 主体、成员、蓝图、正式修订或检查运行变化后，旧规则理由、资格依据和验收依据均不恢复；过期人工决定被拒绝 |
| 复核输入恢复 | 规则理由、资格依据和验收依据可在刷新后恢复；不同主体、账号和复核范围之间不串用 |
| 需求 Agent 请求 | 长调用持久化请求编号、状态和结果；断线或刷新后按原请求恢复，不重复生成版本；模型不可用时旧草案保持不变 |
| 提交者闭环 | 字段、材料、草稿、正式提交和回执分开显示；上传不等于正式提交，正式回执保留该版本的附件清单 |
| 并发保护 | 草稿、上传和删除操作核对服务器版本；旧标签页冲突时保留当前输入和已选文件，要求用户重新核对 |
| 交付完整性 | 快照固定后导出 CSV 与 ZIP 使用同一版本，写入前校验附件字节数和哈希；历史导出可恢复并验证 |
| Agent 边界 | Skill、工具白名单、预算、最大输出、幂等键、审计脱敏和人工接管开关均有自动化合同测试 |

## 限制

验证使用虚构人物、虚构材料、隔离服务和空模型密钥，证明的是版本隔离、恢复、权限与流程行为，不是模型准确率。真实 provider 文件输入、真实屏幕阅读器、实体移动设备、并发部署和公网安全仍需在获准环境中单独验收。
