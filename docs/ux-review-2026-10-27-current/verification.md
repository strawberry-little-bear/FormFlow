# 验证记录：运行证据与展示路径

> 这是一份历史验证存档：记录指定版本、数据和环境下的用户可见结果。它不是产品介绍、开发日报或未来承诺。

**验证日期**：2026-10-27
**场景**：交付快照、Agent runtime、失败态恢复、展示视图和提交者路径
**环境**：隔离演示服务；虚构种子；未配置模型密钥
**性质**：版本验证存档

## 结论

当前展示路径能够把“需求整理、规则检查、人工接手、快照交付”讲清楚，也能在失败时给出下一步。交付快照保持不可变；无效名册和复核编号不会永久停在加载态；窄屏展示视图可以收起运行细节；模型不可用时会显示脱敏原因和人工处理入口。

## 已验证能力

| 能力 | 验证结果 |
| --- | --- |
| 快照状态 | 无快照时提示先固定；已有快照显示类型、编号和时间；再次固定不会覆盖旧快照或导出包 |
| Agent runtime 合同 | 根据真实工具注册表、Skill 白名单、输入/结果上限、预算和人工接管开关完成自测；不读取材料正文，也不调用模型 |
| 启动与检查 | `--port` 使用请求端口；`--check` 能分别报告种子、API、Worker、runtime 合同和 MCP 只读桥状态 |
| 名册与复核失败态 | 404 会替换加载占位，提供重试或返回入口；无效任务不允许继续导入或复核 |
| 提交者窄屏路径 | 1440、390、320px 登录、填写、上传、草稿和提交路径无整页横向溢出 |
| 复核失败接手 | 模型不可用、预算耗尽、材料读取失败和其他失败使用中文原因、影响和下一步；可重新排队或进入人工复核 |
| 展示视图 | 桌面默认展开运行证据，窄屏默认收起；快捷入口会展开对应区域并移动焦点 |
| 设计台状态 | 当前运行摘要显示需求整理、核对澄清和确认发布阶段；发布后提示版本冻结 |
