## 记录格式

每份档案只回答四件事：

1. **场景**：使用的数据、设备和配置。
2. **结果**：访客完成了什么，页面显示了什么。
3. **证据**：截图、脚本、自动化结果或复现命令。
4. **边界**：没有覆盖的 provider、材料、设备或生产条件。

日期、端口、提交号和测试数量只用于复现定位。档案中的“通过”只代表指定环境下的行为已经核对，不代表真实模型质量或公网部署已经验收。

历史走查记录保留原始事实；产品介绍、实现计划和未来承诺放在根目录 README、部署文档或路线图中。
