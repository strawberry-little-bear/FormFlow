## 档案怎么读

1. **场景**：数据、设备、配置和入口。
2. **结果**：用户完成了什么，页面显示了什么。
3. **复现**：脚本、截图和运行条件。
4. **边界**：没有覆盖的 provider、材料、设备或生产条件。

历史档案保留事实，但不承担产品介绍或开发日报的职责。档案中的“通过”只表示指定环境下的行为已经核对，不代表真实模型质量、屏幕阅读器体验或公网部署已经验收。真实材料应使用获准的脱敏数据单独评估。
