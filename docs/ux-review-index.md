## 如何阅读档案

1. **场景**：使用的数据、设备、配置和入口。
2. **观察**：访客完成了什么，页面显示了什么。
3. **结论**：这次验证支持哪些产品判断。
4. **复现与边界**：如何重跑，以及哪些 provider、材料、设备或生产条件没有覆盖。

日期、端口、提交号和测试数量只用于复现定位。档案中的“通过”只代表指定环境下的行为已经核对，不代表真实模型质量、屏幕阅读器体验或公网部署已经验收。历史记录保留事实，但不承担产品介绍和开发进度汇报的作用。
