## 每份档案包含什么

1. **场景**：使用的数据、设备、配置和入口。
2. **结果**：用户完成了什么，页面展示了什么。
3. **复现**：脚本、截图和运行条件。
4. **边界**：没有覆盖的 provider、材料、设备或生产条件。

这些记录用于帮助访客理解和复核产品行为，不是产品宣传稿，也不是按日期排列的开发日报。虚构种子和离线轨迹可以验证流程、权限、状态和导出行为；真实材料、模型质量、敏感数据处理、屏幕阅读器和公网部署需要在获准环境中单独验收。
