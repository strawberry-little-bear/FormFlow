## 使用者路径

组织者从演示登录进入任务列表，新建任务、选择“团课报告”模板并发布；导入一位虚构提交者、发放一次性凭证，再进入提交者页面。提交者先尝试空表提交，确认被拦截并聚焦缺项；补齐字段、上传 PDF、保存服务器草稿后正式提交。组织者随后复核并记录验收，建立正式快照、生成 CSV 和 ZIP。
