# 验证档案：空库首次启动与完整闭环

**场景**：从空库创建任务，再完成组织者与提交者闭环
**环境**：临时工作副本、未配置模型密钥、虚构种子、本地浏览器
**用途**：验证首次启动和最小可用流程

## 用户路径

组织者从演示登录进入任务列表，新建任务、选择“团课报告”模板并发布；导入一位虚构提交者、发放一次性凭证，再进入提交者页面。提交者先尝试空表提交，看到缺项提示；补齐字段、上传 PDF、保存服务器草稿后正式提交。组织者随后复核、记录验收、建立正式快照并生成 CSV 和 ZIP。

## 结果

- 页面完成从空库到归档的业务闭环，上传、草稿、正式提交、验收、快照和导出请求均成功返回。
- 390px 和 320px 下设计、名册及提交者页面无整页横向溢出，主要操作文字没有裁切。
- 浏览器控制台错误、页面异常、失败 HTTP 响应和意外 Agent 请求均为 0。

## 限制与证据

该场景只覆盖空库启动、离线种子和本地浏览器，不代表真实模型质量、provider 文件输入兼容性或公网部署安全。截图和复现脚本位于同目录；可使用 `scripts/ux_first_task_submitter_entry_walkthrough.cjs` 重跑。
