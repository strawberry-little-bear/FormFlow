# 2026-11-04 提交者键盘操作与触控尺寸复核

## 发现与处理

认证后提交者表单桌面端实测中，“重新加载服务器草稿”和“上传”按钮约 31px 高，文件选择控件约 42px、保存草稿约 43px，辅助操作尺寸不齐。将草稿重载和上传按钮最小高度统一为 42px，更新样式缓存版本，并增加前端契约防止回退。首次调整被通用 `.ghost.sm` 规则覆盖；提高专用选择器优先级后，浏览器计算尺寸达到预期。
