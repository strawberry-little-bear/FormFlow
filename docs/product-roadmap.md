# FormFlow 产品状态与方向

FormFlow 目前是一条可展示的材料收集与审核流程：组织者整理要求并发布任务，提交者填写并提交材料，审核 Agent 按规则给出逐项结论，组织者完成确认后导出交付快照。

## 当前能力

### 从资料生成收集任务

组织者可以提供通知、名单、模板、附件和补充说明。需求 Agent 将资料整理为可编辑的收集蓝图，包含字段、材料槽位、格式要求、截止时间、跨材料核验规则和需要确认的冲突。每项要求保留来源引用，发布前由组织者确认。

### 从材料生成审核结果

提交者填写身份信息并上传多份材料后，审核 Agent 按已发布规则检查身份一致性、文件属性、内容覆盖和需要人工判断的事项。结果逐条展示结论、解释、文件和位置，并区分 `satisfied`、`issue`、`unknown` 与 `failed`。

### 让 Agent 在边界内运行

Skill 固化资料提取、规则编译、证据引用和输出格式；Harness 约束工具、范围、预算、超时、重试和人工接管；MCP 只提供受限的只读运行上下文。确定性检查由程序完成，模型负责理解、比对和解释。

### 让文件输入可控

文件审核优先使用部署者配置的 provider 原始 PDF 或图片能力。provider 不支持、文件超限或调用失败时，系统才进入文字解析或 OCR 降级路径。API Key 只保存在部署者本地配置，不进入数据库、浏览器、审计事件或日志。

## 下一步方向

| 方向 | 目标 |
| --- | --- |
| 来源资料管理 | 支持替换、版本化、差异比较和更细的解析状态 |
| 审核工具 | 增加页级预览、结构化格式检查和更可靠的证据回链 |
| 组织者工作台 | 让筛选、催交、补正和验收围绕下一步动作组织 |
| 提交者体验 | 强化条件材料、弱网恢复、可访问性和多轮更正 |
| 生产部署 | 支持共享数据库、队列租约、对象存储、备份恢复和审计保留 |
| 质量评估 | 在获准脱敏材料上按规则类型和文件类型建立评估阈值 |

## 验证边界

虚构种子和离线轨迹用于验证流程、权限、状态和导出行为，不能证明真实模型准确率。真实 provider 的文件输入、模型质量、敏感材料处理、屏幕阅读器、实体移动设备和公网安全需要在授权环境中单独验收。
