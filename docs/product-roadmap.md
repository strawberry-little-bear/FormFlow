## 产品主张与不做什么

围绕一个收集任务提供完整闭环：要求 → 收件 → 有证据的补正 → 人工验收 → 正确版本交付。先验证团课材料场景，再验证团队比赛报名的复用性。不扩展成通用流程引擎，不做文章打分、真实性认定或 AI 写作检测。

判断一次迭代是否值得做：**它是否减少一次找入口、猜状态、重复填写或拿错版本？** 不以多一个聊天窗口或多一张统计图作为完成标准。

## Agent 工具运行时：内部 Harness 与外部 MCP 分层

**已落地最小内部运行时**：`app/agent_tools.py` 定义严格输入/输出 Schema、显式工具 allowlist、授权 scope、成本/调用预算、幂等键、结果大小上限、协作截止时间、失败类型和审计记录；`app/agents/tooling.py` 提供受限 `review_one_submission` skill，仅可按当前正式蓝图调用单条程序规则或语义规则；`app/services/checks.py` 将它接入真实审核执行路径。模型不会自行决定工具名称、SQL、文件路径、授权主体、规则 ID 或网络目的地。每次调用在审计事件里附当前主体、检查运行、规则 ID、工具类型、结果状态及耗时；复核 Findings 只向该任务的授权组织者展示当前运行轨迹，界面可展开查看逐步运行记录。

**需求起草的长调用恢复**：`app/services/agent_requests.py` 将起草/修订先落库再执行，按任务顺序串行处理，使用任务+账号+请求 ID 唯一键与 payload 哈希防止断线重放；请求状态可由所有者读取，API 响应丢失时前端先查状态，再按同一请求编号幂等补投。页面将请求 ID 与当前输入暂存在原有 owner/task sessionStorage 中，重载后恢复用户原文、显示队列/运行状态并继续查进度。超时/无效模型回应不会生成新版本；旧草案保留，允许用同一请求编号重试。新草案/并发修订的基线不再最新时 fail closed，要求刷新，避免旧结果覆盖新版本。Worker 按配置的模型最长调用预算设置宽裕租约并恢复超期 running job；attempt fence 阻止迟到的旧 Worker 提交结果。

此请求队列是 SQLite/单 API 单 Worker 的本地应用机制，不是分布式任务系统；部署多副本前仍需共享数据库上的行锁/租约设计、死信管理、退避和监控。后台任务与 Worker 可同时尝试同一任务请求，但一次只处理该任务头部队列请求。

安全边界和限制：参数/结果验证失败、越权、预算耗尽、超时、运行异常一律 fail closed 为 `failed`，由现有审核状态交给人工或重试；审计只记录工具名、执行者账户范围、主体/运行/规则 ID、状态、耗时、模拟标记及幂等键哈希，不保存原始材料、参数或结果。授权 Findings API 仅为组织者读取当前检查运行的过滤后轨迹；旧运行的轨迹不混进新版本。幂等回放缓存是单次 harness 生命周期内存态，未承诺跨进程 exactly-once。skill 对失败停止策略与需人工处理项留痕有显式控制。截止时间通过 context 传给工具协作执行；Python 无法强制杀死忽略 deadline 的 handler，新增 handler 必须把剩余时限传入阻塞 I/O，且不得启用脱离请求的副作用。此实现是本地应用内的受控 skill/harness，不是通用规划 Agent，也不会调用外部 MCP 工具。

**2026-10-25 增加可选外部 MCP 互操作入口**：`app/mcp_server.py` 是独立 stdio adapter，供用户主动配置的 MCP 客户端调用。它映射三个只读 API：`list_my_tasks`、`get_task_next_step` 和 `get_task_agent_runtime`。runtime 工具让外部 Agent 在协助某个任务前读取已发布的 Skill、工具白名单、Harness 限额、MCP 边界和人工接手点，回应评委现场“Agent 到底能做什么、不能做什么”的展示问题。API Bearer 会话继续经过 `current_account` 与 `_owned_task` 授权，adapter 对所有结果做字段白名单投影，不提供 participant、evidence、prompt、audit 或写操作工具。token 只从 sidecar 进程环境读取，远程 API 要求 HTTPS，明文 HTTP 限定 loopback。此 adapter 服务外部客户端的只读协作互操作，不扩大网页内模型权限；工具描述和 MCP `readOnlyHint` 明确标注只读。

本轮补上真实 stdio 子进程契约测试：通过独立 MCP 客户端完成工具发现和三项调用，并验证 Bearer 转发、只读标记、中文往返及敏感字段过滤。演示服务实连也已完成；网页 Agent 仍未连接 sidecar，不能把外部互操作描述成模型已在网页内调用 MCP。
